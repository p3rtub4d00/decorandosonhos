# Decorando Sonhos

Site institucional responsivo para a empresa **Decorando Sonhos**, criado com HTML, CSS e JavaScript puro.

## Configuração rápida

Abra `script.js` e substitua:
- `55SEUNUMERO` pelo WhatsApp com DDI + DDD + número, somente dígitos.
- `SEUUSUARIO` pelo usuário do Instagram, sem @.

## Fotos reais

A seção "Nossos Trabalhos" já está pronta para o layout. Na próxima etapa, as ilustrações podem ser substituídas pelas fotos reais dos trabalhos mantendo o mesmo design.

## Rodar localmente

Basta abrir `index.html` no navegador ou usar uma extensão como Live Server.
